# Contactos

| Módulo | Lectura | Escritura |
| --- | --- | --- |
| **Contactos** | listar libretas de direcciones personales y compartidas; buscar y leer contactos, incluido el catálogo de cuentas de solo lectura de la instancia (compañeros, con `accountId` para invitaciones), según la configuración de enumeración de usuarios del administrador | crear y editar conservando los campos vCard desconocidos; eliminar permanentemente solo después de verificar una copia `.vcf` de seguridad en `/MCP backups/Contacts` |
